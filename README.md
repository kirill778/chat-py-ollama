# Ollama Chat

Современный и стильный чат-интерфейс на Python для взаимодействия с языковыми моделями через Ollama. Приложение предоставляет красивый пользовательский интерфейс с анимациями и эффектами для общения с различными языковыми моделями.

## Основные возможности

- 🎨 **Современный дизайн** с красивыми анимациями и эффектами
- 🤖 **Поддержка различных моделей** (llama3, llama2, mistral, gemma, phi)
- 🔄 **Асинхронное взаимодействие** с Ollama API
- 📱 **Адаптивный интерфейс** с возможностью изменения размера окна
- 💬 **Анимированные чат-сообщения** с эффектами появления и исчезновения
- 🔔 **Уведомления** о смене модели и событиях
- 🌈 **Премиум-цветовая схема** для приятного пользовательского опыта

## Требования

Для запуска приложения необходимы:

- Python 3.7+
- Установленный и запущенный [Ollama](https://ollama.ai/)
- Загруженные модели в Ollama (минимум одна из поддерживаемых)
- Библиотеки Python: tkinter, Pillow, requests

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/kirill778/chat-py-ollama.git
cd chat-py-ollama
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка Ollama

1. Скачайте и установите [Ollama](https://ollama.ai/) с официального сайта
2. Запустите Ollama
3. Загрузите нужные модели с помощью команды:
   ```bash
   ollama pull llama3
   ```
   Вы можете загрузить и другие поддерживаемые модели: llama2, mistral, gemma, phi

### 4. Запуск чата

```bash
python ollama_chat.py
```

## Использование

1. **Отправка сообщений**: Введите текст в поле внизу и нажмите кнопку "Отправить" или клавишу Enter
2. **Смена модели**: Выберите другую модель из выпадающего списка в правом верхнем углу
3. **Перенос строки**: Используйте Ctrl+Enter для добавления новой строки в сообщении
4. **Навигация**: Боковое меню позволяет быстро переключаться между разделами

## Особенности реализации

- Полностью реализован на Python с использованием стандартной библиотеки Tkinter
- Поддерживает все современные эффекты и анимации без использования сторонних UI-фреймворков
- Асинхронное взаимодействие с API для плавного пользовательского опыта
- Оптимизированная загрузка и отрисовка графических элементов

## Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Ошибка подключения к API | Убедитесь, что Ollama запущен и доступен по адресу http://localhost:11434 |
| Ошибка загрузки модели | Проверьте, загружена ли выбранная модель в Ollama |
| Проблемы с отображением графики | Установите последнюю версию Pillow: `pip install --upgrade Pillow` |
| Ошибки с размещением элементов | Обновите Tkinter до последней версии, доступной для вашей ОС |

## Системные требования

- **Windows**: Windows 10 или новее
- **macOS**: macOS 10.14 (Mojave) или новее
- **Linux**: Ubuntu 18.04+, Debian 10+, Fedora 30+, или другие совместимые дистрибутивы
- **Оперативная память**: минимум 4 ГБ (рекомендуется 8+ ГБ для работы с большими моделями)
- **Процессор**: двухъядерный или лучше
- **Дисковое пространство**: ~100 МБ для приложения (не включая пространство для моделей Ollama)
